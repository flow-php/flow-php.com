A split block bloom filter: blocks of eight little-endian u32 words, one bit set per word for each value.

The eight bits a hash sets in a bitset of $blocks blocks, numbered from the first byte's lowest bit. $hash is the xxh64 u64 as a signed PHP int, so every shift is masked and the 32-bit multiply is split in 16-bit halves.
