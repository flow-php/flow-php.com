SinkAttachment

FinalYes
SinkAttachment.php : 33

Attaches a plan's sink roots to the spine: the step each spine node gains for them. attach() is the entry; the other methods are the walk it runs. SinkFeedFactory builds the pipelines the walk hands rows to.
