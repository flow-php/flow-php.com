WritePlanner

FinalYes
WritePlanner.php : 30

Attaches a plan's write roots to the spine: the step each spine node gains for them. attach() is the entry; the other methods are the walk it runs. A write with steps of its own becomes a branch: the pipelines the runtime feeds batch by batch.
