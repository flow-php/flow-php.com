ValueEquality

Read onlyYes
FinalYes
ValueEquality.php : 43

SQL equality: two columns of different types compare in one type, as DuckDB binds them. Numbers widen to float, a date to a datetime, and a string casts to the other side's type; a string that does not cast throws.
