batches()

FileBatches.php : 31

Batches of one file of $read under $body (file constants excluded), every column built by $backend, in $read->batchSize rows; $criteria carries the split and the conjuncts.

public batches(FileRead $read, Criteria $criteria, SourceFile $source, Schema $body, Backend $backend, ReadWindow $window) : Generator<mixed, int>

The return value is the rows of the window's offset this file consumed. A format that cannot skip rows is given offset 0 and a limit that counts the offset still to skip, and returns 0: FileReadLoop slices the offset from its rows. An OffsetSkippingFileBatches is given the offset and returns the rows it skipped. The limit is a hint a format may exceed - FileReadLoop trims what goes past it - and null when the read carries conjuncts, whose rows FileReadLoop counts. FileReadLoop applies the conjuncts to every row returned; a format given them when built may skip what they prove cannot match.

A file's own resources are released by the generator (finally); those that span files go at close().
